# ML-detection-against-BE-HT

The proposed dataset comprises of total 196 instances of Trojan infected and non-BE-HT infected designs. 
There are 56 instances of BE-HT infected designs in the dataset, while there are 140 instances of non-BE-HT designs in the dataset. Moreover, there are 4 attack instances (BE-HT infected variations) per benchmark in the dataset.
